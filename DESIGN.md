# Design System: Orbital Brutalism — Zero Vector Design

## 1. Visual Theme & Atmosphere

Zero Vector's visual identity is Orbital Brutalism — a design system that treats the screen like a gallery wall and the interface like a printed artifact. It draws from the typographic austerity of the MoMA identity and the unapologetic scale of the Stendig Calendar: if something matters, make it enormous and give it room to breathe. If it doesn't, cut it.

The foundation is pure black and white. No gradients, no soft shadows, no border-radius, no ambient blur. Every surface has a hard edge. Every container has a visible boundary — a 1px solid border or a 4px offset shadow, never both pretending to be subtle. The palette is binary: a thing is either figure or ground, present or absent.

Neon accents — pink (`#ff00fb`), green (`#00ff80`), orange (`#ffaa00`) — exist as punctuation, not decoration. They mark actions, highlight state changes, and draw the eye to exactly one thing at a time. They are never used for backgrounds larger than a single card or label. They earn their presence.

Typography is Proxima Nova at 700 weight for display, Inter for body. Subtitles use Courier in neon orange — a deliberate anachronism that signals "this is a system talking to you." All text is sentence case. Nothing is uppercase. Letter-spacing is tight or zero, never loose.

Interactions are immediate and mechanical. Hover states flip: white becomes black, black becomes neon. Transitions are 150ms with a cubic-bezier ease-out. Cards lift with `translateY(-6px)` on a spring curve. Nothing fades in gently. Nothing bounces. The system responds like a switch, not a spring.

The philosophy behind the aesthetic: a site about eliminating the gap between intent and artifact should itself feel like an artifact — not a template, not a theme, not something that could have been generated by dragging blocks around a canvas. Every pixel is a deliberate decision, and the design makes that visible.

**Key Characteristics:**
- Pure black and white foundation — no gray backgrounds, no soft neutrals
- Zero border-radius on all containers, cards, buttons, and inputs — hard edges only
- Neon accents as punctuation: pink (`#ff00fb`), green (`#00ff80`), orange (`#ffaa00`)
- Proxima Nova 700 for display, Inter for body, Courier for system subtitles
- 4px offset box-shadows (`4px 4px 0 #000`) for elevation — never soft shadows
- Hover states are binary flips: white→black, text→neon. No partial opacity, no gentle fades.
- 150ms transitions with `cubic-bezier(0.16, 1, 0.3, 1)` ease-out — snappy, mechanical
- Negative letter-spacing on display type (`-0.04em` to `-0.03em`) — tight, engineered

## 2. Color Palette & Roles

### Primary Surfaces
- **Void (White)** (`#ffffff`): Page canvas, card backgrounds, nav item backgrounds. The default surface — figure is always on white ground.
- **Void Surface** (`#fafafa`): Subtle surface tint for resource cards and secondary containers. One shade below pure white.
- **Black** (`#000000`): Inverted sections, hover states, dropdown panels, footer. The counter-surface.

### Neon Accents
- **Neon Pink** (`#ff00fb`): Primary action color — CTA buttons, sign-in, nav hover text, outline buttons, "before" eyebrow labels. The loudest accent.
- **Neon Green** (`#00ff80`): Secondary accent — section titles on black backgrounds, "after" eyebrow labels, nav-start hover text. Signals success, progress, the new way.
- **Neon Orange** (`#ffaa00`): System voice — Courier subtitles, callout text, resource card type labels. Signals "the system is speaking."

### Text
- **Text Primary** (`#000000`): Body text, headings, nav items on white backgrounds. Pure black — no warm or cool tinting.
- **Text Secondary** (`#333333`): Supporting body copy, card descriptions. One step lighter for hierarchy.
- **Text Tertiary** (`#666666`): Metadata, muted labels, timestamps. Clearly receded.
- **Text Muted** (`rgba(0, 0, 0, 0.4)`): Placeholder text, disabled states, background coordinates.

### Text (Inverted — on black sections)
- **Text Primary Inverted** (`#ffffff`): Headings and body on black backgrounds.
- **Text Secondary Inverted** (`#cccccc`): Supporting copy on black.
- **Text Tertiary Inverted** (`#999999`): Muted content on black.

### Border
- **Border Default** (`rgba(0, 0, 0, 0.08)`): Light structural border for white sections — nav mobile menu divider, subtle card edges.
- **Border Inverted** (`rgba(255, 255, 255, 0.1)`): Structural border for black sections.
- **Border Hard** (`#000000`): 1px solid black — dropdown panels, button outlines, hard-edge containers. The primary border.

### Shadow
- **Offset Shadow** (`4px 4px 0 #000`): The signature — hard-edge offset, no blur. Used on dropdown panels, pipeline cards. Never soft, never blurred, never ambient.

### Focus
- **Focus Ring** (`#ffaa00`): 2px solid outline with 3px offset. Neon orange for keyboard focus visibility.

## 3. Typography Rules

### Font Family
- **Primary**: Proxima Nova, with fallback: -apple-system, sans-serif. Self-hosted from `/fonts/proxima-nova/` as OTF. 10 weights available (300–900). Used for all display type.
- **Monospace**: Courier, Courier New, monospace — the "system voice" for subtitles. Deliberate anachronism.
- **Body**: Inter, with fallback: -apple-system, BlinkMacSystemFont, sans-serif

### Hierarchy

| Role | Font | Size | Weight | Line Height | Letter Spacing | Notes |
|------|------|------|--------|-------------|----------------|-------|
| Hero Title | Proxima Nova | clamp(4rem, 12vw, 10rem) | 700 | 0.95 | -0.04em | Enormous, room-filling. The single most important text on any page. |
| Section Title | Proxima Nova | clamp(1.75rem, 4vw, 2.75rem) | 700 | 1.1 | -0.03em | Black on white sections, neon-green on black sections. |
| Subtitle | Courier | clamp(0.85rem, 1.5vw, 1.05rem) | 700 | 1.5 | normal | Neon orange. The system's voice. Always follows a title. |
| Callout | Proxima Nova | clamp(1.25rem, 3vw, 1.75rem) | 700 | 1.3 | normal | Neon orange. Pull-quote emphasis. |
| Eyebrow | Proxima Nova | 0.8rem | 700 | 1.3 | 0 | Neon pink (before) or neon green (after). Card category labels. |
| Body | Inter | 1rem (16px) | 400 | 1.7 | normal | Max-width 720px. The readable column. |
| Card Title | Proxima Nova | 1rem | 600 | 1.3 | normal | Resource cards, nav items. |
| Card Description | Inter | 0.85rem | 400 | 1.5 | normal | Supporting text in cards. #333 on white. |
| Nav Item | Proxima Nova | 1rem | 700 | 1.2 | -0.01em | White box, black text. Flips on hover. |
| Button | Proxima Nova | 1rem | 700 | 1.2 | normal | CTAs. Same treatment as nav items. |
| Card Type | Proxima Nova | 0.8rem | 700 | 1.3 | 0 | Neon orange. Resource card category labels. |

### Principles
- **Sentence case everywhere**: Nothing is uppercase. No `text-transform: uppercase`. No ALL CAPS headings. Sentence case signals confidence without shouting.
- **700 weight is the signature**: Display type is always bold. There is no light or medium display weight. Bold carries authority.
- **Tight tracking on display sizes**: `-0.04em` at hero scale, `-0.03em` at section scale. Creates dense, engineered blocks of text. Normal tracking at body sizes.
- **Courier as system voice**: Subtitles in Courier + neon orange create a deliberate tension — a monospace typewriter font in a modern interface signals "this is the system speaking to you directly."
- **Max-width 720px on body text**: No line of body copy extends past 720px. Readability over spectacle at body scale.

## 5. Layout Principles

### Spacing System
- Container max-width: 1100px, centered
- Container padding: 24px (mobile: 20px)
- Section padding: `clamp(48px, 8vh, 80px)` vertical (info pages: tighter at `clamp(40px, 6vh, 64px)`)
- Mobile section padding: `clamp(32px, 6vh, 48px)`
- Body text max-width: 720px

### Grid Patterns
- Resource cards: 2-column grid, 12px gap (3-column variant for reading lists)
- Contrast pairs: 2-column side-by-side
- Pipeline: 2-column
- All grids collapse to single column on mobile

### Whitespace Philosophy
- **Cinematic scale**: Hero titles fill the viewport. Section titles claim their space. Body text is bounded but generous (line-height 1.7). The system alternates between spectacle (titles) and reading comfort (body).
- **Black/white rhythm**: White sections alternate with black sections, creating a dramatic pacing — cinematic cuts, not smooth scrolls. Each section inversion is a new scene.
- **Nothing is decorative**: Every element is content or structure. There are no decorative borders, no ornamental dividers, no accent lines that don't communicate state.

## 6. Depth & Elevation

| Level | Treatment | Use |
|-------|-----------|-----|
| Flat (Level 0) | No shadow, white background | Page canvas, standard sections |
| Surface (Level 1) | `#fafafa` background, no shadow | Resource cards, subtle containers |
| Inverted (Level 2) | `#000000` background, white text | Alternating sections, hover states |
| Elevated (Level 3) | `4px 4px 0 #000` offset shadow | Dropdown panels, pipeline cards |
| Hover lift | `translateY(-2px)` to `translateY(-6px)` | Cards on hover, interactive elements |
| Focus ring | `2px solid #ffaa00`, 3px offset | Keyboard focus visibility |

**Depth Philosophy**: Orbital Brutalism rejects soft shadows entirely. Depth is communicated through two mechanisms only: background color inversion (white→black) and hard-edge offset shadows. The offset shadow (`4px 4px 0 #000`) is a typographic convention borrowed from letterpress printing — the shadow is a physical object, not atmospheric light. It declares "this element is above the surface" without pretending to simulate real-world lighting.

## 7. Do's and Don'ts

### Do
- Use pure `#000000` and `#ffffff` as the only background colors — the binary is the identity
- Use `border-radius: 0` on everything except the nav Start pill (which gets 40px — the one exception)
- Use `4px 4px 0 #000` for all elevated elements — hard-edge offset, never blurred
- Use neon pink (`#ff00fb`) for primary actions and destructive emphasis
- Use neon green (`#00ff80`) for positive states, section titles on black, and "after" states
- Use neon orange (`#ffaa00`) for Courier subtitles and callout text — the system's voice
- Use `2px solid #000` for button borders — visible, structural, not decorative
- Use sentence case for all text — never uppercase, never title case
- Use 150ms transitions with `cubic-bezier(0.16, 1, 0.3, 1)` — snappy, mechanical
- Use `translateY(-2px)` to `(-6px)` for card hover lifts
- Use Proxima Nova 700 for all display type — bold is the only display weight

### Don't
- Don't use border-radius on cards, buttons, inputs, or containers — the system is hard-edged
- Don't use soft shadows (`box-shadow: 0 4px 12px rgba(...)`) — only offset shadows
- Don't use gradients for backgrounds or text — the palette is flat and binary
- Don't use gray backgrounds (`#f5f5f5`, `#eee`, etc.) — surfaces are white or black, nothing in between
- Don't use neon accents for large backgrounds — they are punctuation, not surfaces
- Don't use uppercase text — no `text-transform: uppercase` anywhere
- Don't use light or medium font weights for display type — 700 only at display scale
- Don't use loose letter-spacing on display text — always tight (`-0.04em` to `-0.03em`) or normal
- Don't animate with opacity fades or bounce easing — transitions are instant flips
- Don't add decorative elements (dividers, accent lines, ornamental borders) — everything is content or structure

## 8. Responsive Behavior

### Breakpoints
| Name | Width | Key Changes |
|------|-------|-------------|
| Small Phone | <480px | Hero titles clamp down, section padding tightens, body font 16px |
| Mobile | <768px | Single column, nav collapses to hamburger, CTAs go full-width (min-height 48px), coordinate display hidden |
| Desktop | >768px | Full layout, multi-column grids, absolute-positioned nav over hero |

### Touch Targets
- CTAs on mobile: full-width, 16px 28px padding, `min-height: 48px`
- Nav items: 0.4em 0.85em padding, adequate touch area
- Mobile nav links: full-width touch targets in the slide-down panel

### Collapsing Strategy
- Hero title: `clamp(4rem, 12vw, 10rem)` → scales fluidly, never breaks
- Section titles: `clamp(1.75rem, 4vw, 2.75rem)` → `clamp(1.25rem, 5vw, 1.75rem)` at 480px
- All multi-column grids (resource cards, contrast pairs, pipeline, philosophy splits): collapse to single column at 768px
- Section padding: 80px desktop → 48px mobile → 32px small phone
- Container padding: 24px → 20px at 768px
- Nav: absolute (desktop) → fixed (mobile) for scroll overlay behavior

### Touch Device Adaptations
- Hover-dependent interactions disabled via `@media (hover: none)` — pipeline card hover lift suppressed, nav link size change suppressed
- All interactive elements accessible without hover

### Iteration Guide
1. Backgrounds are `#fff` or `#000` — never gray, never off-white, never tinted
2. All border-radius is `0` — the only exception is the Start pill (40px radius)
3. Offset shadow is `4px 4px 0 #000` — never blurred, never soft, never ambient
4. Neon accents: pink for action, green for positive/titles-on-black, orange for system voice
5. Display type is always Proxima Nova 700 with tight letter-spacing
6. Subtitles are always Courier 700 in neon orange
7. Body text is Inter 400 at 1rem, max-width 720px, line-height 1.7
8. Hover states are binary flips — white→black, text→neon. No partial states, no opacity tricks
9. Transitions: 150ms, `cubic-bezier(0.16, 1, 0.3, 1)`. No bounces, no elastic easing
10. Card lifts: `translateY(-2px)` for subtle, `translateY(-6px)` for dramatic
