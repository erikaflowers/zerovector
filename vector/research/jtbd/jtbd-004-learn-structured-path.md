# JTBD-004: Learn via Structured Path

**Priority:** High
**Personas:** persona-001 (Frustrated Designer), persona-002 (Solo Practitioner)

## Job Statement

When I want to transition from AI-curious to shipping real applications, I want a structured curriculum that respects my existing expertise and builds on it, so I can develop genuine capability instead of collecting tutorial fragments.

## Current Alternatives

- YouTube tutorials — fragmented, inconsistent quality, no progression model
- Bootcamps — expensive, time-intensive, assume career switchers not skill expanders
- Documentation reading — necessary but insufficient for building judgment
- Learning by doing (vibe coding) — builds speed without foundations

## Evidence

- Open Vector: "60+ lessons teaching design-led engineering from first principles" — free, structured
- Investiture progression levels (00–05): explicit mastery ladder from awareness to mastery
- Start page: Entry point designed to assess where someone is and route them appropriately
- Seven Principles: "Work in the Medium" — learn by building in the real material, not reading about it
